# Phase 4: The Action Layer (Interventions)

This directory tracks the **Active Intent** of the system. It documents the interventions, projects, and experiments performed by MiNYAMA agents.

## 🔴 Active Theaters

### 1. [ICTAZ](ictaz/)
Information and Communications Technology Association of Zambia student chapter activities.
*   *Focus:* Bridging academic theory with industry practice via the "Sector Spotlight Series."

### 2. [ZUDS](zuds/)
Zambia Urban Digital Systems.
*   *Focus:* Infrastructure-level digital transformation projects.

### 3. [Applied Projects](applied_projects/)
General field operations and pilot programs.

## 🛠 The Learning Loop
Every intervention must be preceded by a **Baseline Expectation** and followed by a **Surprise Audit**. If an action does not result in a learning event, it is documented as a failure of the model.
