# Validation Spec: Evidence Requirements

Evidence is the "Sensory Input" that updates the MiNYAMA world model. To maintain systemic integrity, all files in `evidence/` must meet these observational standards.

---

## 1. Acceptable Evidence Types

### 📡 Empirical (Sensory)
Direct measurements from the environment (e.g., IoT telemetry, transaction logs, assessment scores).
*   **Standard**: High-fidelity, timestamped, and traceable to a source hardware/software ID.

### 🧪 Simulation (Synthetic)
Data generated by the system's internal engines for "what-if" analysis.
*   **Standard**: Must be explicitly labeled as `[SYNTHETIC]` and include the parameters of the generating model.

### 🤖 Mock (Structural)
Low-fidelity data used ONLY for Level 1/2 Hardening or CI testing.
*   **Standard**: Must never be used in a Level 3+ (Functional) report.

---

## 2. Metadata & Traceability

Every evidence record must include the following metadata block (either in a header or a sidecar JSON):

| Field | Requirement | Description |
| :--- | :--- | :--- |
| `timestamp` | Mandatory | ISO 8601 format of the observation event. |
| `source_id` | Mandatory | The unique ID of the sensor, agent, or process that generated the data. |
| `uncertainty_sigma` | Recommended | The degree of confidence in the measurement (used for surprise weight). |
| `provenance` | Mandatory | A hash or path tracing back to the rawest form of the data. |

---

## 3. Uncertainty Handling

Active Inference models depend on the "Precision" of sensory input.
*   **Rule**: Evidence with high `uncertainty_sigma` (low precision) results in a smaller "Model Update" even if the "Surprise" is large.
*   **Constraint**: Data without a defined uncertainty level will be assigned a `default_penalty_weight` of 0.5.

---

## 4. Compliance Examples

### ✅ Compliant (Agri Soil Sensor)
```json
{
  "zone_id": "ZONE_ALPHA",
  "sensor_id": "SOIL_V3_128",
  "timestamp": "2026-05-09T12:00:00Z",
  "data": { "moisture": 0.42, "nitrogen": 12.5 },
  "uncertainty_sigma": 0.05,
  "provenance": "raw_telemetry/iot_hub/stream_A_09.log"
}
```

### ❌ Non-Compliant (Vague Observation)
```text
"The soil looks a bit dry today. Probably needs water."
- Error: No timestamp, no unique sensor ID, no quantitative moisture level, no uncertainty sigma.
```
