# MiNYAMA: A System for Socio-Economic Modeling and Analysis

**MiNYAMA** is a project dedicated to modeling, simulating, and analyzing complex socio-economic systems using the principles of Active Inference. It provides a framework for understanding and predicting the dynamics of various sectors within a given environment.

## Project Status

This project is currently in the initial stages of development. The core modeling framework is being built, and the sectoral schemas are being defined.

## Core Concepts

The methodology is centered around **Active Inference**, a theoretical framework from computational neuroscience. In this context, the "system" (e.g., a city or region) is treated as an agent that actively seeks to maintain its own stability and order. It does this by:

1.  **Modeling the World:** Building an internal "world model" based on incoming data (priors).
2.  **Minimizing Surprise:** Constantly making predictions and updating its model to minimize the difference between its predictions and what it actually observes (prediction error or "surprise").

The goal of this project is to leverage this approach to gain insights into the complex interplay of different societal sectors.

## Directory Structure

The repository is organized into three main components:

-   `1_System_Schemas/`: This directory contains the foundational data models or "schemas" that define the structure, entities, and relationships for each sector (e.g., Agriculture, Healthcare, Finance). These are the building blocks of the world model.

-   `2_Active_Inference_Model/`: This is the heart of the project. It contains the Python source code for the active inference engine.
    -   `src/data_model/`: Code for data representation, including graph structures and state tensors.
    -   `src/inference_engine/`: The core logic for running simulations, calculating surprise, and updating the world model.
    -   `environmental_priors/`: Data and assumptions that inform the model's initial state.

-   `3_Sector_Reports/`: This directory holds the analytical output. The reports are generated by the model and provide insights, predictions, and analyses for each sector.

## Usage

The primary interaction with the project is through the Markdown files:

1.  **Schemas** in `1_System_Schemas/` can be modified to change the fundamental structure of the model.
2.  The model is run (details to be specified).
3.  **Reports** in `3_Sector_Reports/` are generated and can be reviewed to understand the outcomes of the simulation.

The entire system is designed to be managed as a knowledge base, with [Obsidian](https://obsidian.md/) being the recommended tool for navigating and editing the project's content.
